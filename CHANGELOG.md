# Changelog

## 1.0.0

- Added configurable workflow module groups, modules, definitions, levels, and transitions.
- Added publishable settings, instance-history, action-button, and modal views.
- Added configurable web/API routes and a host-application menu descriptor.
- Added workflow lifecycle events, including completed and rejected hooks.
- Added `HasWorkflows` model integration.
- Added assignment-provider support for polymorphic users, roles, positions, units, and departments.
- Added configurable, scoped, concurrency-safe number sequences with format tokens and resets.
- Added materialized user inbox items with New, Pending, Attended, Responded, Held, and Ended counters.
- Added default workflow inbox views, JSON counters, named routes, and sidebar menu descriptors.
- Preserved the original workflow-instance API endpoints as compatibility aliases.
